# Chojema InputLens for macOS

## 한국어

macOS 12 이상에서 Apple Silicon과 Intel Mac을 지원합니다.

1. DMG를 열고 **Chojema InputLens.app**을 **Applications**로 드래그합니다.
2. 응용 프로그램 폴더에서 앱을 실행합니다. 메뉴 막대에 키보드 아이콘이 나타납니다.
3. 앱은 Apple 배포용 서명·공증이 없습니다. macOS에서 실행을 차단하면 한 번 실행을 시도한 뒤 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**를 사용합니다.
4. **시스템 설정 → 개인정보 보호 및 보안 → 입력 모니터링**에서 앱을 허용합니다. 목록에 없으면 **+**로 응용 프로그램 폴더의 앱을 추가합니다. 허용 후 앱을 종료하고 다시 실행합니다.
5. 메뉴 막대 아이콘에서 일시정지, 마우스 표시, 언어, 정보, 종료를 선택합니다. Dock에는 아이콘이 나타나지 않습니다.

ZIP을 사용하는 경우 압축을 풀고 앱을 응용 프로그램 폴더로 옮깁니다.

일반 타이핑은 표시하지 않으며 입력을 파일에 저장하거나 전송하지 않습니다. 암호 입력 등 보안 입력이 활성화된 동안에는 키보드 입력이 표시되지 않을 수 있습니다. 일시정지하면 입력 수신을 중단합니다.

## English

Supports Apple Silicon and Intel Macs running macOS 12 or later.

1. Open the DMG and drag **Chojema InputLens.app** to **Applications**.
2. Launch the app from Applications. A keyboard icon appears in the menu bar.
3. The app has no Apple distribution signature or notarization. If macOS blocks it, attempt to launch it once, then use **System Settings → Privacy & Security → Open Anyway**.
4. Allow the app under **System Settings → Privacy & Security → Input Monitoring**. If it is missing, use **+** to add the app from Applications. Quit and reopen the app after granting permission.
5. Use the menu bar icon for Pause, Show mouse, Language, About and Quit. There is no Dock icon.

For the ZIP, extract it and move the app to Applications.

Ordinary typing is hidden. Input is never saved to a file or sent anywhere. Keyboard events may be unavailable during Secure Input, such as password entry. Pause stops input reception entirely.
